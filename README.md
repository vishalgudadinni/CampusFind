# CampusFind

CampusFind is a campus-focused lost and found platform that helps students report, discover, match, verify, and recover lost items.

The platform also provides a virtual Campus Coin reward system for students who successfully return lost items.

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Tailwind CSS
- Framer Motion
- Socket.IO
- Git & GitHub
